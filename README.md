# First-runr

A 14-second, 9:16 vertical motion graphic promo for the First-runr running app, built with plain HTML, CSS and JavaScript (no build step).

## View it

Open `index.html` in a browser.

- **Space**: play / pause
- **R**: restart
- **H**: hide the controls (for screen recording)
- Add `?clean` to the URL to start with the controls hidden.

## Make it a video

1. Open `index.html?clean` in a tall browser window. The 1080×1920 stage scales to fit.
2. Screen-record one loop. It runs 14 seconds and starts and ends on black, so it loops seamlessly.

## Customize

Edit the `CONFIG` block at the top of the `<script>` in `index.html` to change the brand name, tagline, feature chips, run stats and call to action. Colors are the CSS variables in `:root`.
